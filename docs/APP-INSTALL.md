# 하루 앱 직접 설치 가이드

스토어를 거치지 않고 설치하는 방법입니다.

| 기기 | 파일 | 권장 |
|---|---|---|
| 안드로이드 | `Haru.apk` | 앱 설치 |
| 아이폰 | `Haru-unsigned.ipa` | 사파리 "홈 화면에 추가"를 먼저 권장 |

## 아이폰은 먼저 이걸 고려하세요

| | 홈 화면에 추가 | IPA 직접 설치 |
|---|---|---|
| 푸시 알림 | 옴 | **안 옴**(유료 Apple 개발자 계정이 필요) |
| 유효 기간 | 제한 없음 | **무료 Apple ID는 7일마다 다시 서명** |
| 준비물 | 사파리만 | PC + 케이블 + 서명 도구 |

앱 아이콘으로 쓰는 것이 목적이면 사파리에서 사이트를 열고 **공유 → 홈 화면에 추가**가 가장 간단합니다.

---

## 아이폰에 IPA 설치 (Windows + Sideloadly)

IPA는 서명이 없는 상태로 배포됩니다. Sideloadly가 설치할 때 본인 Apple ID로 서명합니다.

### 처음 한 번 준비

1. **IPA 받기:** [app-latest 릴리스](https://github.com/DoyeonKR/our-days/releases/tag/app-latest)에서 `Haru-unsigned.ipa`를 받습니다.
2. **iTunes와 iCloud 설치:** Microsoft Store 버전이 아니라 **Apple 웹사이트의 Windows 설치 파일**을 써야 합니다. Store 버전이 깔려 있으면 지우고 다시 설치하세요.
3. **Sideloadly 설치:** [공식 사이트](https://sideloadly.io)에서 받습니다. 비슷한 이름의 다른 사이트는 쓰지 마세요.
4. **Apple ID:** 설치에 쓰는 Apple ID로 로그인합니다. 부담되면 설치 전용 Apple ID를 새로 만들어도 됩니다. 2단계 인증 코드를 물으면 입력합니다.

### 설치

1. 아이폰을 USB 케이블로 PC에 연결하고, 아이폰에서 **이 컴퓨터를 신뢰** → 암호 입력을 합니다.
2. Sideloadly에서 위쪽 칸에 아이폰이 보이는지 확인합니다.
3. `Haru-unsigned.ipa`를 창으로 끌어다 놓습니다.
4. **Apple account** 칸에 Apple ID를 입력하고 **Start**를 누릅니다.
5. 비밀번호와 인증 코드를 입력하고 `Done`이 나올 때까지 기다립니다. 케이블을 빼지 마세요.

### 아이폰에서 허용

1. **설정 → 일반 → VPN 및 기기 관리**에서 내 Apple ID를 눌러 **신뢰**합니다.
2. iOS 16 이상은 **설정 → 개인정보 보호 및 보안 → 개발자 모드**를 켜고 재시동합니다. 재시동 후 묻는 화면에서 **켜기**를 누릅니다.
3. 홈 화면의 **하루**를 엽니다. 카메라 권한을 물으면 허용하세요.

### 7일마다 다시 서명

무료 Apple ID로 설치한 앱은 7일이 지나면 열리지 않습니다.

- **앱을 지우지 말고** 위 설치 과정을 다시 하면 그 위에 덮어씁니다.
- 계정 데이터는 서버에 있으므로 다시 로그인하면 그대로 나옵니다.

### 막힐 때

| 증상 | 해결 |
|---|---|
| Sideloadly에 아이폰이 안 보임 | Store 버전 iTunes인지 확인, 케이블 교체, 다시 "신뢰" |
| "신뢰할 수 없는 개발자" | 설정 → 일반 → VPN 및 기기 관리에서 신뢰 |
| 앱 아이콘을 눌러도 안 열림 | 개발자 모드 확인, 7일이 지났으면 다시 서명 |
| 앱 개수 제한 오류 | 무료 Apple ID는 직접 설치 앱이 **3개까지**입니다. 하나를 지우세요 |

## 안드로이드에 APK 설치

1. `Haru.apk`를 폰으로 옮깁니다(카카오톡 나에게 보내기, USB 등).
2. 폰에서 파일을 열고 **출처를 알 수 없는 앱 허용**을 켭니다.
3. **설치**를 누르고, 앱을 열어 로그인합니다.
4. **알림 허용**을 묻으면 허용합니다.

예전 테스트 APK를 설치했다면 서명이 달라 업데이트가 안 됩니다. **예전 앱을 지우고** 설치하세요. 기록은 서버에 있어 사라지지 않습니다.

### 삼성폰에서 알림이 늦으면

설정 → 앱 → 하루 → 배터리 → **제한 없음**으로 바꿉니다.

### 알림이 안 오면

앱의 설정 → 알림 칸이 지금 상태를 알려 줍니다.

| 칸에 뜨는 말 | 할 일 |
|---|---|
| 알림이 꺼져 있어요 | 휴대폰 설정 → 애플리케이션 → 하루 → 알림 → 허용. 돌아와서 **다시 확인** |
| 아직 알림을 허용하지 않았어요 | **알림 켜기** → 허용 |
| 이 휴대폰이 아직 등록되지 않았어요 | 인터넷 연결을 확인하고 **다시 등록** |
| 이 휴대폰으로 앱 알림이 와요 | **이 휴대폰으로 테스트 알림**으로 확인 |

알림 종류(쿡 찌르기 · 기념일 · 일정 · 오늘의 질문 · 활동 · 리마인더)는 휴대폰 설정 → 앱 → 하루 → 알림에서 따로 끌 수 있습니다.
앱을 켜 둔 동안 온 알림이 화면 위에 뜨려면 2026-11-06 이후 APK(버전 1.2)가 필요합니다. 그 전 APK 는 앱 안에 짧은 안내로 대신 보여 줍니다.

## 알아 둘 점

- 앱은 배포된 사이트를 엽니다. 웹을 고치면 앱을 다시 설치하지 않아도 반영됩니다.
- 인터넷이 없으면 "인터넷에 연결되면 열려요" 화면이 뜹니다.
- 저장·공유 버튼은 휴대폰의 공유 시트를 엽니다. 사진첩 저장이나 카카오톡 전송을 거기서 고르세요.
- 미디어 포함 백업(ZIP)이 200MB 를 넘으면 여러 파일로 나뉩니다. 앱은 "N개 중 k번째 파일"을 하나씩 물어보며 공유 시트를 엽니다 — 모든 파일을 저장해야 백업이 완성됩니다.
- 일기책의 PDF 저장은 앱에서 지원하지 않습니다. PDF가 필요하면 브라우저에서 사이트를 열어 만드세요.
