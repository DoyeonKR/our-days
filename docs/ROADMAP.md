## 결정 완료 (브이로그)

- [x] **로그 retention**: 자동 삭제하지 않고 영구 보관. 기록 허브와 월간 리캡에서 과거 기록으로 진입.
- [x] **고아 미디어 서버 GC**: 자동 스케줄 없음. `media-gc`를 dry-run으로 확인한 뒤 명시적으로
  `confirm=true`를 보낼 때만, 24시간 이상·DB 전 참조 2회 미검출 파일을 회당 200개까지 정리.

## IA 메모

하단 탭은 목적 중심 5개로 고정한다.

| 상위 탭 | 하위 기능 |
|---|---|
| 홈 | 오늘 상태, 빠른 행동, 다가오는 일정 3개 |
| 기록 | 오늘 로그, 일기, 사진 |
| 계획 | 일정, 버킷리스트 |
| 함께 | 커플 연결·초대, 활동함, 장거리 카드, 무드, 질문, 추억 리캡 |
| 게임 | 섬과 아케이드 |

새 기능은 위 목적지의 하위 세그먼트나 설정 영역에 배치한다. 하단 탭 추가와 홈 카드 무한 증식을 금지한다.
